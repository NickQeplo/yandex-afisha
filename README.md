# Анализ лояльности пользователей Яндекс Афиши

## О проекте
**Цель:** изучить поведение пользователей и понять, какие клиенты возвращаются и совершают повторные заказы.

## Данные
- **Источник:** PostgreSQL, выгрузка через SQLAlchemy.
- **Период:** 01.06.2024 – 31.10.2024 (5 месяцев).
- **Объём:** 290 611 заказов, 21 933 пользователя.
- SQL-запрос выгрузки — в `data_analysis.sql`.
- `final_tickets_tenge_df.csv` — курс тенге к рублю за 2024 год.

## Что сделано
1. Загрузка и предобработка: типы данных, конвертация тенге в рубли, анализ пропусков и выбросов.
2. Профиль пользователя: агрегация по `user_id` (первый заказ, регион, оператор, тип мероприятия, средний чек, число билетов, интервал между заказами, признаки `is_two`/`is_five`).
3. EDA: сегментация по признакам первого заказа, анализ выручки и состава заказа, временные характеристики, корреляционный анализ (phi_k).
4. Выводы и рекомендации.

## Основные результаты
- Возвращаются 61.8% пользователей (2+ заказа), 29.2% — 5+ заказов.
- Сильнейшие сигналы первого заказа: регион (55.2–68.6%) и тип мероприятия (54.7–64.0%).
- Лучший сегмент по билетам: 2–3 билета — 74% возвратов; худший: 5+ — 19%.
- День недели почти не влияет (размах 4.5 п.п.).
- Сильнейшая корреляция числа заказов — с интервалом между ними (phi_k 0.39 / 0.70).
