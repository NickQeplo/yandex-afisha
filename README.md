# Анализ лояльности пользователей Яндекс Афиши

## О проекте
**Цель:** изучить поведение пользователей платформы, чтобы понять факторы, влияющие на возвратность и формирование постоянных клиентов.

## Данные
- **Источник:** PostgreSQL (выгрузка через SQLAlchemy/DBeaver), сохранена в `data/data_mart.csv`.
- **Период:** 01.06.2024 – 31.10.2024 (5 месяцев).
- **Объём:** 290 611 заказов, 21 933 пользователя (до очистки).
- **Справочник валют:** `final_tickets_tenge_df.csv` (курс тенге к рублю за 2024 год).
- **SQL-запрос формирования витрины:** представлен в файле `data_analysis.sql`.

## Что сделано
1. **Предобработка данных:** 
   - Оптимизация типов данных (`category`, `int8`, `float32`).
   - Конвертация выручки из тенге в рубли.
   - Обработка пропусков (интервалы между заказами) и выбросов (невалидные транзакции, дубликаты).
   - Удаление аномального аккаунта с 10 057 заказами; обоснование сохранения остальных высокоинтенсивных профилей.

2. **Профиль пользователя:** 
   - Агрегация по `user_id`: 
    - первый заказ (регион, устройство, тип мероприятия, оператор), 
    - средний чек, 
    - количество билетов, 
    - интервалы, 
    - признаки лояльности (`is_two`, `is_five`).

3. **Исследовательский анализ (EDA):** 
   - Сегментация по признакам первого заказа и проверка гипотез о возвратности.
   - Анализ влияния выручки и состава заказа (количество билетов) на удержание.
   - Исследование временных характеристик (день недели, интервалы между покупками).
   - Корреляционный анализ с использованием коэффициента Phi-k.

4. **Выводы и рекомендации:** 
   - Формирование списка факторов, влияющих на возвращение пользователей.
   - Рекомендации для маркетинговых команд по удержанию сегментов.

## Основные результаты
- **Уровень возврата:** 61.8% пользователей совершают 2+ заказа, 29.2% — 5+ заказов.
- **Ключевые точки входа:** Регион и тип мероприятия влияют сильнее всего. Выставки и Театр показывают лучшую конверсию (>64%), Спорт — худшую (~55%).
- **Поведенческие паттерны:** Покупка 2–3 билетов ассоциируется с максимальной лояльностью (74% возвратов). Покупки от 5 билетов носят преимущественно разовый характер (19% возвратов).
- **Время:** День недели первой покупки практически не влияет на дальнейшее поведение (размах долей <5 п.п.). Интервал между заказами сильно коррелирует с общим числом покупок (Phi-k до 0.70 для сегмента 5+).
- **Концентрация спроса:** ~1% аккаунтов генерируют около половины всех заказов. Они оставлены в выборке, но отмечены в ограничениях анализа.
